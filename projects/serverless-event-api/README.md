# Serverless Event API — Terraform + Python

An original portfolio demonstration of AWS Lambda infrastructure-as-code. This is **Blake Brown's example application**, not a fork or copy of the Terraform module.

## What it demonstrates
- Python Lambda handler for validating and pricing a small order
- Input validation, structured JSON replies and deterministic unit tests
- Terraform deployment using the upstream `terraform-aws-modules/lambda/aws` module
- AWS IAM execution role generated by the module, short retention for CloudWatch logs
- Function URL with AWS IAM authentication (no public anonymous endpoint)

## Run locally (no AWS required)

```bash
cd projects/serverless-event-api
python -m unittest discover -s tests -v
python -c 'from src.handler import lambda_handler; print(lambda_handler({"body": "{\"items\":[{\"sku\":\"A1\",\"quantity\":2,\"unit_price_cents\":1250}]}"},None))'
```

## Optional AWS deployment (may incur charges)

Requires AWS CLI credentials and Terraform. Review plans, IAM policies, and pricing **before** deployment.

```bash
cd terraform
terraform init
terraform validate
terraform plan
# Run terraform apply only after reviewing the plan and cost implications.
```

To remove provisioned resources, use `terraform destroy`. The included app doesn't require DynamoDB, API Gateway, or a paid third-party service.

## Architecture

Client with AWS SigV4 credentials → IAM-protected Lambda Function URL → Python handler → JSON response / CloudWatch logs.

The browser showcase is a local JavaScript demonstration of the *same calculation* with editable inputs; it doesn't invoke AWS.
